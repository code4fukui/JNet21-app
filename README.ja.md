# JNet21-app

日本の中小企業（SME）向け支援策の一覧を表示するウェブアプリケーションです。

## デモ
ライブデモはこちら: [https://code4fukui.github.io/JNet21/](https://code4fukui.github.io/JNet21/)

## 機能
- 中小企業向け支援策の一覧を表示
- キーワードによる一覧のフィルタリングが可能
- 各項目から公式の支援策ページへリンク
- 日付、カテゴリ、タグなどのメタデータを表示

## データ / API
データは、[Code for FUKUI](https://github.com/code4fukui/JNet21)がGitHub上でホストしているCSVファイルから取得しています。このデータの元となる情報は、日本の中小企業向けビジネス支援サイトである[J-Net21](https://j-net21.smrj.go.jp/index.html)から収集されたものです。
