# JNet21-app

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A web application that displays a list of support measures for small and medium-sized enterprises (SMEs) in Japan.

## Demo
Live demo available at: [https://code4fukui.github.io/JNet21/](https://code4fukui.github.io/JNet21/)

## Features
- Displays a list of SME support measures
- Allows filtering the list by keyword
- Each item links to the official support measure page
- Displays metadata such as date, category, and tags

## Data / API
The data is fetched from a CSV file hosted on GitHub by [Code for FUKUI](https://github.com/code4fukui/JNet21), which is sourced from the [J-Net21 website](https://j-net21.smrj.go.jp/index.html), a business support site for SMEs in Japan.
